Miner Project

Ein Bergbau-Spiel, das als schmales Fenster über dem Desktop liegt: 1000 Minen, 5000 Rohstoffe und ein Skillnetz mit elftausend Knoten, das sich in alle Richtungen verzweigt.

Launcher

Prüft beim Start, ob eine neuere Version bereitliegt, lädt sie und startet das Spiel. Das Projekt liegt privat, deshalb braucht die Prüfung ein Lesetoken — ohne Token startet der Launcher die Version, die im selben Ordner liegt.

Erster Start

  1. ZIP in einen eigenen Ordner entpacken.
  2. Windows fragt beim ersten Start eventuell nach einer Bestätigung — die exe ist nicht signiert.
  3. Die .NET 8 Desktop-Runtime installieren, falls sie fehlt.
  4. Im Spiel: Maus über den Minenarbeiter halten, das Ringmenü öffnet sich.
